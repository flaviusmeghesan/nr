Adauga conturi din link

Lipeste linkurile paginilor (Instagram / Facebook / TikTok), cate unul pe linie. Recunosc singur platforma si numele contului - nu completezi nimic.

Clienti

Conturi

Un cont = un client pe o platforma. ID-ul si tokenul sunt necesare doar daca vrei sincronizare automata.

Echipa

Cine posteaza. Apare in dreptul fiecarei postari.

Plan saptamanal

Cate postari de fiecare tip trebuie publicate. Planul standard (orice saptamana) se aplica automat; poti pune o valoare diferita doar pentru saptamana selectata.

Import din export (Meta Business Suite / TikTok Studio)

Descarci exportul de postari al clientului (Business Suite > Content > Export Data, sau TikTok Studio > Download data) si il urci aici. Aplicatia ghiceste ce inseamna fiecare coloana; confirmi o data, iar data viitoare o retine automat pentru aceeasi platforma.

Alege mai intai clientul si contul.

Sincronizare automata

Trage postarile direct de pe pagini, prin browserul tau. Te loghezi o singura data cu python3 run.py --login, apoi merge in fundal. Din terminal poti sincroniza tot deodata cu python3 run.py --sync.

Import rapid (format propriu)

Pentru un tabel facut de voi, cu coloanele: client, platforma, cont, tip, status, planificat_pe, postat_la, titlu, link, autor, descriere.
